UR Learning website starter

Files:
- index.html        homepage
- styles.css        design and layout
- script.js         mobile menu and small interactions
- assets/ur-learning-logo.png

To publish on your existing GitHub Pages repository (steelertough/urlearning):
1. Open the repository on GitHub.
2. Upload index.html, styles.css, script.js, and the assets folder.
3. If GitHub asks about replacing your old index.html, replace it.
4. Commit the changes to the main branch.
5. GitHub Pages will automatically redeploy.
6. Visit https://urlearning.org after deployment completes.

Tip: Keep the folder name "assets" exactly as-is because index.html refers to assets/ur-learning-logo.png.
